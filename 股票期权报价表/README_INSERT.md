# 期权报价数据插入SQL生成器

这个项目包含一个JavaScript脚本，用于从Excel文件的第二行开始生成数据插入的SQL语句，可以直接导入到已创建的数据库中。

## 文件说明

- `generate_insert_sql.js` - 数据插入SQL生成脚本
- `check_insert_sql.js` - 用于检查生成的SQL文件内容
- `中信中证资本期权报价表2025-08-20origin.xlsx` - 原始Excel数据文件
- `yudao_excel_daily_insert.sql` - 生成的数据插入SQL文件
- `yudao_excel_daily建表语句.sql` - 数据库表结构文件

## 功能特点

### 1. 字段名处理
- 自动处理包含"Exp."的字段名，去除括号及其内容
- 例如：`1M(Exp.25/09/22）` → `1M`
- 支持中英文括号的处理

### 2. 数据插入
- 从Excel文件第二行开始处理数据
- 自动处理NULL值和空值
- 字符串值自动转义单引号
- 数值类型保持原格式

### 3. 生成的SQL特点
- 只包含INSERT语句，不包含CREATE TABLE
- 适用于已存在的数据库表
- 包含详细的注释信息

## 使用方法

### 1. 安装依赖
```bash
npm install xlsx
```

### 2. 运行脚本
```bash
node generate_insert_sql.js
```

### 3. 检查结果
```bash
node check_insert_sql.js
```

## 数据库导入步骤

### 1. 创建数据库表
首先使用 `yudao_excel_daily建表语句.sql` 创建数据库表：

```sql
-- 执行建表语句
source yudao_excel_daily建表语句.sql;
```

### 2. 导入数据
然后使用生成的数据插入SQL文件导入数据：

```sql
-- 执行数据插入语句
source yudao_excel_daily_insert.sql;
```

## 注意事项

1. **确保数据库表已存在**：在运行插入脚本前，必须先创建数据库表
2. **数据格式**：脚本会自动处理数值和字符串格式
3. **空值处理**：Excel中的空值会被转换为NULL
4. **特殊字符**：字符串中的单引号会被自动转义
5. **字段匹配**：确保Excel文件的字段顺序与数据库表字段顺序一致

- **处理时间**：约2-3秒

## 错误处理

如果遇到以下问题：

1. **字段不匹配**：检查Excel文件第一行字段名是否与数据库表字段一致
2. **数据类型错误**：确保Excel中的数据格式正确
3. **文件读取失败**：检查Excel文件是否存在且格式正确

## 性能优化建议

1. **批量插入**：可以考虑将INSERT语句合并为批量插入以提高性能
2. **事务处理**：建议在事务中执行插入操作，便于回滚
3. **索引优化**：在插入大量数据前，可以临时禁用索引，插入后再重建
